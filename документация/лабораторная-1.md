# Лабораторная 1

Источник: [Лабораторная 1](https://github.com/iu5git/Web#лабораторная-1). Репозиторий `artwork-exhibition-backend`, ветка `sprint-1-artwork-catalog`.

## Цель курса

Тема на семестр, бэкенд на шаблонах, дизайн. Хранилище файлов — MinIO из `docker-compose.yml` (`9000` API, `9001` консоль, пользователь `root`).

## Что сдать по порядку показа

1. Текст темы и соответствие заданию.
2. Макет трёх экранных сценариев курса (лента, черновик, плитка) и те же экраны в приложении. Главная и страница автора — дополнительные.
3. Сайт-образец Prado и перечень того, что перенесено в CSS: три цвета, наведение, форма карточки. См. `стиль-prado.md`.
4. Три GET во вкладке Network: лента с id, черновик, плитка с `creation_year`.
5. В HTML ответа плитки — URL изображения и видео из MinIO; в коде — поля коллекции и использование в трёх шаблонах.
6. Роутинг: URL и обработчики, фильтр на сервере.

Контрольные вопросы курса: MVT, компоненты MVC, шаблонизация, HTTP и OSI, Web, HTML.

## Ограничения

- Портретная вёрстка, нижняя панель из трёх пунктов.
- Лента: видео играет само, текст и кнопки поверх. Снизу краткое описание, справа год, зал, счётчик отметок, кнопка «следующее».
- Черновик: те же поля столбиком. Сверху слоты изображения и видео, ниже текст и поля темы. Запись не выполняется.
- Плитка: два столбца; картинка, название, число отметок, год. Фильтр по `creation_year` сохраняется в поле.
- Одна коллекция в памяти. Три GET курса. Без БД и без JavaScript.
- В коллекции есть черновик (он на странице этикетки) и снятая работа (в интерфейсе её нет).
- `GET` ленты без id открывает ленту с панели. `?next=true` открывает следующее произведение после id.

## Меню

Шапка на всех страницах по `.example/heder/heder.md`:

- Главная
- Коллекция (`/explore-artworks`)
- Художники (якорь или первая страница автора)
- Выставки (главная, блок текущей экспозиции)

Нижняя панель курса: Лента, Черновик этикетки, Коллекция.
