# Предметная область

**Система:** интеллектуальная информационная система «Художественные выставки».

**Сейчас:** каталог произведений для лабораторных 1–2. Позже — рекомендации посетителю и аналитика для музея (поддержка решений по экспозиции).

## Роли

| Роль | Кто | Лабораторные 1–2 |
| --- | --- | --- |
| Посетитель (гость) | Смотрит коллекцию | Лента, плитка, страница автора, главная |
| Куратор (создатель) | Готовит этикетку произведения | Черновик без записи в лаб. 1; создание и публикация в лаб. 2 |
| Аналитик музея | Решения по выставке | Вне объёма лаб. 1–2 |

## Как требования курса легли на тему

В курсе сущность называется «услуга». В этой работе это **произведение в экспозиции**.

| Курс | ArtExpert |
| --- | --- |
| Услуга | Произведение, таблица `artworks` |
| Лента | Карточка произведения с вертикальным видео |
| Плитка | `/explore-artworks` |
| Добавление | `/curator/wall-label`, черновик этикетки |
| Лайк | Отметка посетителя, `visitor_appreciations` |
| Пользователь | `visitors` |
| Черновик / опубликован / удалён | `in_preparation` / `on_display` / `withdrawn` |
| Два поля темы | `creation_year`, `gallery_hall` |
| Фильтр плитки | Год создания, число, не текст |

Имена `service`, `order`, `cart`, `basket`, `search`, `text` в таблицах, полях, URL и шаблонах не использовать.

## Страницы первой очереди

Ориентир — Museo del Prado, разметка в `.example`.

1. `/` — главная и меню.
2. `/explore-artworks` — плитка коллекции.
3. `/the-collection/art-work/the-nobleman-with-his-hand-on-his-chest/9` — произведение.
4. `/artist/el-greco-domenikos-theotokopoulos/` — все работы автора в экспозиции.

Пятый маршрут нужен для защиты курса: `/curator/wall-label` (форма черновика, в лаб. 1 без сохранения).
