# Стиль по `.example`

Образец: сайт Museo del Prado. В репозитории лежит разметка, не их CSS. В `static/css/exhibition.css` повторяется композиция, не копируется чужой файл стилей.

## Что взять из файлов

| Файл | Куда |
| --- | --- |
| `.example/heder/heder.md` | Шапка: логотип, пункты меню, поиск как ссылка на коллекцию |
| `.example/footer/footer.md` | Подвал колонками: визит, коллекция, выставки |
| `.example/article/ficha.md` | Блок произведения: крупное изображение и подпись «сведения о работе» |
| `.example/article/mas-obras.md` | Ряд других работ на странице автора и под карточкой |
| `.example/article/section.md` | Текстовые секции главной |
| `.example/filter-featured-group-stickyFacetas/filter-featured.md` | Полоса фильтра над плиткой; в лаб. 1 одно числовое поле года |
| `.example/tab-horizontal-dragscroll-scroll/tab-scroll.md` | Горизонтальный ряд разделов меню |

## Три цвета

| Роль | Код |
| --- | --- |
| Текст, логотип, рамки панелей | `#181818` |
| Фон страницы | `#f4f1ea` |
| Акцент меню, ссылка при наведении | `#8c1d18` |

Наведение: `text-decoration: underline` и цвет `#8c1d18`. Карточка: фон `#ffffff`, граница `#e6e1d8`, изображение с отношением сторон 3/4, название под изображением, без скругления больше 2px.

Шрифт заголовков — serif (`Georgia`, `Times New Roman`). Меню и подписи — sans-serif (`Segoe UI`, `Helvetica`, `Arial`).

Для скриншотов защиты перечислить в CSS комментарием эти три кода, правило `:hover` и блок `.artwork-card`.
