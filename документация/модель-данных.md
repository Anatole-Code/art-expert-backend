# Модель данных

Имена — предметные. Каскадное удаление запрещено.

## artworks

| Столбец | Смысл | Тип |
| --- | --- | --- |
| artwork_id | PK | integer |
| artwork_title | Название | varchar(200) |
| wall_label | Краткая этикетка | varchar(500) |
| display_status | `in_preparation`, `on_display`, `withdrawn` | varchar(32) |
| image_object_key | Ключ изображения в MinIO | varchar(300) |
| video_object_key | Ключ видео в MinIO | varchar(300) |
| creation_year | Год создания, фильтр плитки | integer |
| gallery_hall | Номер зала | integer |
| artist_name | Автор, атомарная строка | varchar(200) |
| artist_slug | Slug страницы автора | varchar(200) |
| artwork_slug | Slug карточки | varchar(200) |
| catalogued_at | Дата создания записи | timestamp |
| curator_id | FK → visitors | integer |
| label_formed_at | Дата формирования этикетки | timestamp |

`artist_name` и `artist_slug` нужны странице автора. Это скаляры, не вложенные коллекции. Год и зал — обязательные «два поля по теме» курса.

## visitors

| Столбец | Тип |
| --- | --- |
| visitor_id PK | integer |
| visitor_name | varchar(120) |
| visitor_email | varchar(200) |

## visitor_appreciations

| Столбец | Тип |
| --- | --- |
| appreciation_id PK | integer |
| visitor_id FK | integer |
| artwork_id FK | integer |

Уникальная пара `(visitor_id, artwork_id)`.

## Инвариант

У одного `curator_id` не больше одной строки `display_status = 'in_preparation'`.
