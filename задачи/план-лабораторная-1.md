Репозиторий `artwork-exhibition-backend`, ветка `sprint-1-artwork-catalog` от `main`. Как завести оба репозитория: `задачи/спринты-и-репозитории.md`.

## 1. Каркас

- [ ] Модуль Go, `cmd/exhibition/main.go`, маршруты без логики.
- [ ] `static/css/exhibition.css` по `документация/стиль-prado.md`.
- [ ] Общие шаблоны шапки, подвала и нижней панели.
- [ ] MinIO из текущего `docker-compose.yml`, бакет и ключи латиницей для образцов.

## 2. Коллекция

- [ ] Тип `Artwork` и срез в памяти: несколько работ `on_display`, один `in_preparation`, один `withdrawn`.
- [ ] Среди опубликованных — El Greco, id 9, slug `the-nobleman-with-his-hand-on-his-chest`.
- [ ] Отметки вложены списком id посетителей; год и зал — числа.

## 3. Четыре страницы и черновик курса

- [ ] `/` — главная, меню, блок текущей выставки.
- [ ] `/explore-artworks` — плитка в два столбца, форма `creation_year`.
- [ ] `/the-collection/art-work/{slug}/{id}` — лента, `?next=true`.
- [ ] `/artist/el-greco-domenikos-theotokopoulos/` — работы автора.
- [ ] `/curator/wall-label` — черновик, поля без записи.

## 4. Защита

- [ ] Network: три GET, в URL видны id и год.
- [ ] Response плитки: URL MinIO, те же поля в трёх шаблонах.
- [ ] Скриншоты 1–19 по порядку показа курса, файл `.doc`.
- [ ] Ответы на контрольные вопросы до показа.

Критерий готовности: меню на всех страницах, снятая работа нигде не видна, фильтр года остаётся в поле, JavaScript не подключён.
