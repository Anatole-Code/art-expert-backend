# Техническое задание

Модуль ТЗ на систему «Художественные выставки». Объём лабораторных 1–2 отмечен отдельно. Полный комплект к РПЗ сдаётся с лабораторной 4.

## 1. Цель

Дать посетителю каталог произведений текущих выставок, а музею — основу для рекомендаций и решений по экспозиции.

## 2. Назначение

Веб-приложение музея. Посетитель смотрит коллекцию, карточку и работы автора. Куратор готовит этикетку: черновик, публикация в зал, снятие с показа. Аналитик музея в лабораторных 1–2 не работает.

## 3. Задачи ближайших этапов

1. Лаб. 1. Шаблоны Go, четыре страницы каталога и форма черновика, MinIO, стили по Prado.
2. Лаб. 2. PostgreSQL, три таблицы, ORM и один SQL `UPDATE`.
3. Дальше по курсу: REST, JWT, React и Redux, адаптив и выкладка.
4. Документация: этот модуль, ER, скриншоты показа.
5. Репозиторий Git с веткой на каждый этап.

## 4. Функциональные требования (лаб. 1–2)

### 4.1. HTTP

Лаб. 1, только GET:

- `/the-collection/art-work/{slug}/{id}` и `?next=true`
- `/curator/wall-label`
- `/explore-artworks?creation_year=`
- дополнительно `/` и `/artist/{slug}/`

Лаб. 2, те же GET из БД и три POST: создать черновик, опубликовать, снять с показа.

### 4.2. Меню

Гость и куратор видят шапку (главная, коллекция, художники, выставки) и нижнюю панель (лента, черновик, коллекция).

### 4.3. Главная

Гость открывает меню и переходит в коллекцию. Отдельный метод API нет, страница собирается из опубликованных произведений.

### 4.4. Плитка

Гость фильтрует по году создания. Куратор в лаб. 2 снимает своё произведение с показа.

### 4.5. Лента

Гость смотрит видео, год, зал, число отметок и переходит к следующему произведению.

### 4.6. Черновик

Куратор заполняет название, этикетку, год и зал. В лаб. 1 данные не сохраняются. В лаб. 2 «Далее» создаёт черновик, «Опубликовать» переводит его в экспозицию.

### 4.7. Автор

Гость видит произведения одного автора со статусом `on_display`.

## 5. Аппаратное обеспечение

Сервер разработки: ПК с Docker Desktop, 4 ГБ свободной памяти под MinIO и PostgreSQL. Клиент: браузер на том же компьютере, портретная ширина от 390px.

## 6. Программное обеспечение

- Go 1.22 или новее, `html/template`, с лаб. 2 — GORM и драйвер PostgreSQL.
- Docker: MinIO `RELEASE.2025-04-22T22-12-26Z` (уже в Compose). PostgreSQL 16 и Adminer — с лаб. 2.
- Клиент: современный браузер без обязательного JavaScript на страницах лаб. 1–2.
